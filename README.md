# 🤖 AI Code Debug & Test Agent

An intelligent developer workflow prototype that helps developers analyze source code, detect potential bugs, generate test cases, suggest fixes, and produce an analysis report.

## 🎯 Problem

Developers often spend time manually debugging code, creating test cases, identifying possible fixes, and documenting results. These repetitive steps can increase development time and rework.

## 💡 Solution

AI Code Debug & Test Agent combines these tasks into one workflow.

### Workflow

Code Input
↓
Bug Detection Agent
↓
Test Generation Agent
↓
Fix Suggestion Agent
↓
Analysis Report

## ✨ Features

- 🐞 Bug detection
- 🧪 Automated test case generation
- 🔧 Fix suggestions
- 📊 Code analysis score
- 🤖 Multi-step agent workflow
- 💻 JavaScript, Python and Java support

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- IBM Bob 2.0

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Select a programming language.
4. Paste source code.
5. Click **Analyze Code**.
6. View bugs, test cases, fix suggestions and analysis report.

## 🤖 IBM Bob 2.0

IBM Bob 2.0 was used to assist with creating, developing, debugging and iterating on the prototype and its developer workflow.
